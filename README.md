# Java Lab Portfolio

## Folder structure

- `index.html` — website structure/content
- `style.css` — design and animations
- `script.js` — Week detail interaction
- `profile.png` — profile picture
- `tasks/` — Week PDF files

## Add another week

Copy a card in `index.html`, change the week number/title/description, and point it to the matching PDF:

`tasks/week-6.pdf`

The same pattern works for Week 7 through Week 12.

## GitHub Pages

Upload the entire folder to a GitHub repository. In the repository, go to:

Settings → Pages → Deploy from a branch → select `main` and `/ (root)` → Save.

The site is static HTML/CSS/JS and is compatible with GitHub Pages.
